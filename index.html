FinStack, the financial backend foundation for your next fintech product

FinStack is an open-source fintech backend starter kit built with NestJS, TypeScript and PostgreSQL. It packages the financial infrastructure I've rebuilt at several companies (wallets, a double-entry ledger, payments, webhooks, FX, idempotency and reconciliation) so teams can focus on their product.

  • No floating-point money. Amounts are integers in minor units and always carry a currency.
  • Double-entry ledger as the source of truth. Every movement balances and entries are immutable.
  • Idempotent by default. Every money-moving endpoint takes an Idempotency-Key, so a retry never moves money twice.
  • Explicit state machines for transactions, enforced in code and by a database trigger.
  • Row-level locking and PostgreSQL transactions for integrity under concurrency.
  • NestJS
  • TypeScript
  • PostgreSQL
